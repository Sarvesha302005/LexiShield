# Changelog

All notable changes to **LexiShield** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [2.1.0] - 2026-10-19

### Added
- **AG Grid Enterprise Workstation:** Dense financial data grid embedded in the Live Dispute Radar tab with sorting, filtering, and CSV export.
- **Postman Automated Evaluation Suite:** Exportable Postman collection and environment files with pre-scripted automated assertions (`pm.test`).
- **Render Cloud Blueprint:** Infrastructure-as-Code `render.yaml` specification for zero-config Docker deployment with persistent disk storage.
- **Enterprise Repository Governance:** Added `LICENSE`, `SECURITY.md`, `.editorconfig`, `.pre-commit-config.yaml`, `CONTRIBUTING.md`, `CODEOWNERS`, and CodeQL security scanning workflows.

---

## [2.0.0] - 2026-10-18

### Added
- **PayPal Seller Protection Guardrails:** Automated enforcement of the $750+ courier signature mandate, AVS exact address token matching, and mid-transit package redirection detection.
- **Visa Compelling Evidence 3.0 (CE 3.0) Engine:** 120–365 day historical ledger lookback with automated 2-factor technical matching (IP & Device Fingerprint).
- **Pre-Chargeback Deflection Hub:** Ethoca Consumer Clarity and Verifi RDR alert ingestion listeners with automated zero-fee refunds to prevent $15–$30 dispute fees.
- **Conversational Settlement Bot:** 3-step autonomous buyer negotiation ladder during the PayPal Inquiry stage.
- **Multi-Tenant SaaS Infrastructure:** PostgreSQL Row-Level Security (RLS) simulation with Bring-Your-Own-Credentials (BYOK) PayPal vaulting.
- **ERP & Accounting Lifecycle Integration:** Double-entry ledger provisioning for frozen funds liability and automated prepaid RMA return shipping label generation.
- **Interactive Web Command Center:** Dark glassmorphism dashboard with live KPI counters, radar feed, and inspection drawers.

---

## [1.0.0] - 2026-10-17

### Added
- **Core Dispute Engine:** FastAPI asynchronous REST API handling `CUSTOMER.DISPUTE.CREATED` and `CUSTOMER.DISPUTE.RESOLVED` webhooks.
- **Multimodal AI Arbitration:** Google Gemini 1.5 Pro multimodal synthesis of warehouse scale telemetry and courier delivery receipts.
- **Mathematical Expected Value Optimizer:** Calibrated $E[V]$ decision branching factoring dispute fee tiering ($15 vs $30).
- **ReportLab PDF Generator:** Automated 3-page audit-ready legal rebuttal dossier compiler.
- **Zero-Trust Webhook Security:** X.509 certificate chain validation, SSRF domain filter, and RSA signature verification.
- **Human-in-the-Loop Queue:** Triage workflow for disputes with order values $> \$300$ or borderline win probabilities.
- **Automated Test Matrix:** Initial pytest test suite covering cryptographic validation, mathematical arbitration, and end-to-end pipeline execution.
